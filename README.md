# Add2Num

Cộng 2 số lớn dạng chuỗi bằng lớp `MyBigNumber` (`src/my_big_number.py`).

Yêu cầu: Python 3.8+, không cần cài thêm thư viện.

## Cài đặt

```bash
git clone https://github.com/levienbang/Add2Num.git
cd Add2Num
git checkout 0.0.1
```

## Chạy chương trình

```bash
python src/main.py 1234 897
```

Hoặc chạy `python src/main.py` rồi nhập 2 số.

## Chạy Unit Test

```bash
python -m unittest discover -s tests -v
```
