# Add2Num

```bash
git clone https://github.com/levienbang/Add2Num.git
cd Add2Num
git checkout 0.0.1
```

## Chạy chương trình

Truyền 2 số qua tham số dòng lệnh:

```bash
python src/main.py 1234 897
```

Hoặc chạy không tham số rồi nhập 2 số từ bàn phím:

```bash
python src/main.py
```


```bash
python -m unittest discover -s tests -v
```
